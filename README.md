# Dulces Lucho App

Aplicación Expo/React Native para catálogo de golosinas, compras y seguimiento de pedidos. Incluye panel de administrador, MySQL e imágenes de productos alojadas mediante ImgBB.

La guía completa de instalación, la explicación de cada archivo, el historial de pedidos y la solución de notificaciones están en [`documentacion.md`](documentacion.md).

## Inicio rápido

1. Importá `database/dulces_lucho.sql`.
2. Configurá y ejecutá `backend` según `backend/.env.example`.
3. Ejecutá `npm install` y `npx expo start` en esta carpeta.
