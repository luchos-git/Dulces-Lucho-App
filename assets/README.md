# recursos visuales de la aplicación

los archivos png son imágenes binarias, por eso no se les puede insertar comentarios sin dañar el archivo. este inventario explica para qué se usan

`images/logo.png` es el logo principal que aparece en las pantallas de acceso

`images/icon.png` es el ícono general configurado para expo

`images/android-icon-background.png`, `images/android-icon-foreground.png` y `images/android-icon-monochrome.png` forman el ícono adaptable de android

`images/splash-icon.png` es la imagen de inicio que expo puede mostrar mientras carga la app

`images/favicon.png` se usa como ícono de pestaña cuando se ejecuta la versión web

`images/logo-glow.png` es una variante gráfica del logo

`images/expo-logo.png`, `images/expo-badge.png`, `images/expo-badge-white.png`, `images/react-logo.png`, `images/react-logo@2x.png`, `images/react-logo@3x.png` y `images/tutorial-web.png` son recursos de ejemplo que quedaron de la plantilla inicial de expo

`images/tabIcons/home.png`, `images/tabIcons/home@2x.png`, `images/tabIcons/home@3x.png`, `images/tabIcons/explore.png`, `images/tabIcons/explore@2x.png` y `images/tabIcons/explore@3x.png` son iconos de pestañas de la plantilla inicial

`expo.icon/Assets/grid.png` y `expo.icon/Assets/expo-symbol 2.svg` son recursos de la plantilla de iconos de expo

`expo.icon/Assets/icon.json` contiene metadatos de la herramienta de iconos de expo
